## 2. Giới hạn kỹ thuật và phân định nguồn mã

1. **Phân biệt mã nguồn Lambda**: **Producer validation đã được triển khai, commit tại `835c840` và push lên `origin/feat/week2-producer-sqs`** (PR #7 vẫn đang mở). Mã nguồn Lambda đang chạy trên AWS Lab của Khôi chưa được chứng minh là có cùng mã hoặc Git commit SHA với commit `835c840`.
2. **Direct Lambda vs API Gateway E2E**: Toàn bộ kết quả Producer PASS ở trên là **direct invocation** trên AWS Lambda console, không phải kiểm thử qua API Gateway `POST /orders`.
3. **Trạng thái E2E và DLQ trên Lab Khôi**: Chưa có ca đối soát khớp `orderId` từ API qua SQS tới item DynamoDB với `status=PROCESSED` tại Lab của Khôi (khác với Lab của Quan đã có E2E hoàn chỉnh). Tương tự, chưa có log retry và kiểm chứng tin nhắn trong DLQ riêng trên Lab Khôi.
4. **Log payload nhạy cảm**: Ảnh `133922` ghi nhận Lambda deployed đang in toàn bộ payload ra CloudWatch. Commit `835c840` (Producer validated) đã được thiết kế để chỉ in `orderId` và `status`, không ghi dữ liệu khách hàng hoặc nội dung đơn hàng.
